# MiSTer Streaming

View MiSTer FPGA video in a browser over LAN, without HDMI capture. No audio or recording.

Usage:
1. Copy `mister_streaming.py`, `mister_streaming.html` and both `.sh` files to `/media/fat/Scripts` on MiSTer.
2. Run `MiSTer_Streaming_on.sh` from MiSTer's Scripts menu.
3. Open `http://<MiSTer-IP>:18765/` on any device on the same LAN. Run `MiSTer_Streaming_off.sh` to stop.

Multiple viewers are supported, but each adds capture and JPEG work.
